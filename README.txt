# İstanbul Trafik Yoğunluğu Tahmin Sistemi
Bu proje, CRISP-DM ve MLOps prensipleri takip edilerek, İBB açık veri portalından alınan 4 yıllık (2020-2024) trafik yoğunluk verileriyle geliştirilmiştir.

## Kullanılan Teknolojiler
- Python 3.13
- XGBoost Regressor (Makine Öğrenmesi Modeli)
- Streamlit (Web Arayüzü)
- Pandas & NumPy (Veri Ön İşleme)

## Çalıştırma Adımları
Terminalden proje klasörüne giderek aşağıdaki komutla arayüzü başlatabilirsiniz:
python -m streamlit run arayuz.py
